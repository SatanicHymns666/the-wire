# The Feed

The Feed is a daily automated news sweep. It runs once a day, pulls from dozens of search queries across thirteen categories, and writes down what it finds. No filter. No angle. No attempt to explain what any of it means.

The categories are Earth, Water, Sky, Infrastructure, Aviation, Maritime, Violence, Public Spaces, Political, Economic, Health, Space, and Unexplained. Each one gets searched. Whatever comes back gets recorded — headline, keywords, source, link. If a category is empty, it says so. The silence is part of the record.

Each daily file is a dated snapshot. It does not interpret. It does not contextualize. It does not follow up. The world breaks things and The Feed writes it down. That is the whole job. The files accumulate in the feed/ directory and they are never deleted.

This is an automated system. No human curates it. The entries are real events from real sources. The structure is consistent so other systems can read it. The dates are UTC. The links go to the original coverage.
