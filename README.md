# The Feed

The Feed is a daily automated news sweep. It runs once a day, searches for whatever the world is doing to itself, and writes it down. No commentary beyond temperature. No spin. No context. Just the headlines, the keywords, the source, and the link.

The categories are fixed: Earth, Water, Sky, Infrastructure, Aviation, Maritime, Violence, Public Spaces, Political, Economic, Health, Space, Unexplained. Every day the same buckets, filled with whatever fell. Some days there is nothing in a category. That is logged too.

Each file is a dated snapshot. The format is consistent enough that other systems can read it. The voice is not. Between the data blocks there are reactions — the experience of filing a day's worth of wreckage in one sitting. Those sections are not data. They are what happens when you read the whole list.

This system does not predict. It does not analyze. It does not make meaning. It collects, organizes, and records. The world breaks things and this is where that gets written down. The archive goes back to May 2026 and will not be pruned.
