# The Feed

The Feed is a daily automated sweep of the news. It runs every day, pulls what broke, and writes it down. No spin. No context. No editorial posture beyond the temperature of the day — what it felt like to be alive on the planet at that particular moment, without anyone explaining why you should care.

Each file is a dated snapshot. Thirteen categories. Earth through unexplained. Headlines, keywords, source, URL. The world generates events whether anyone is watching or not, so someone may as well be watching and writing it down.

This is not a news service. It is a ledger. It does not tell you what to think about an oil spill or a downed helicopter or a virus that has killed six thousand people. It tells you these things happened, on this date, here are the links. That's the whole job.

The system runs daily. The archive doesn't get deleted. The tone is whatever the day earns — quiet days get quiet files, bad days get something heavier. It ends when the world does.
