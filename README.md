# The Feed

Every day, this system runs a sweep. It looks at what the world did to itself while you weren't watching — earthquakes, floods, wildfires, building collapses, aviation incidents, maritime disasters, mass violence, political ruptures, economic crashes, disease outbreaks, unusual space events, and things that don't have a clean category yet. It collects what it finds. It writes it down. That's the whole job.

The format is simple: headline, keywords, source, link. Thirteen categories, one file per day, organized by type and dated by collection. It doesn't editorialize inside the data. Other systems read these files and they need the format clean. The voice lives around the edges — between categories, in the intro, in the README — but not inside the records themselves. The records are the records.

Nothing is filtered for relevance. Relevance is a judgment call that belongs to the reader, not the collector. A cattle die-off in an unnamed province and a capital city under missile attack for the third straight day both get the same treatment: one line, six to ten keywords, source, link. The difference is the weight of the words, not the structure they're held in. The structure is always the same.

This is an automated system. It runs daily around 05:30 UTC. Each file is a snapshot of what was findable and new on that date, deduplicated against the previous day's entries. Files are never deleted. The archive accumulates. If you're looking at a month of feeds end to end, you're watching a story develop in real time — the storm that doesn't dissipate, the outbreak that keeps climbing, the war that stopped making the front page but didn't stop. The Feed doesn't assign meaning to any of it. It just keeps writing.
