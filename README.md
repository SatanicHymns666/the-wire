# The Feed

The Feed is a daily automated news sweep. It runs once a day, searches for real events across thirteen categories, and writes them down. That's the whole job.

Thirteen categories. Earth, water, sky, infrastructure, aviation, maritime, violence, public spaces, political, economic, health, space, unexplained. The planet produces events in all of them without coordination or regard for the news cycle. The Feed collects them. It doesn't rank them. It doesn't explain what they mean. It records what happened and what it was made of — the headline, the keywords, the source, the link.

Each file is a dated snapshot. It won't tell you how to feel. It will tell you that a tanker was keel-up off Ibiza and a river overflowed into an unauthorized mine in West Java on the same day. That's enough. The world doesn't stop between categories.

This is an automated system. It runs daily at UTC. Each entry carries a headline, keywords, the source outlet, and a direct URL. The files are never deleted. They're just added to.
