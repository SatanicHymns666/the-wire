# The Feed

The world breaks things every day. Sometimes it announces it. Usually it doesn't. This is a record either way.

The Feed runs daily, automated, without an editor. It searches across categories — geological events, water disasters, severe weather, infrastructure failures, aviation incidents, maritime disasters, violence, public space emergencies, political crises, economic shocks, disease outbreaks, space events, and unexplained phenomena. Each entry is a headline, a set of extracted keywords, a source, and a link. No editorializing inside the data. Other systems read these files. The format stays clean.

What you're looking at is a dated snapshot: what happened on a given UTC day, organized by category, written down. Sources are verified. Entries are deduplicated against the previous day's file so the same story doesn't run twice. If something was happening yesterday and is still happening today, today has a new article or nothing at all.

This is not a summary service. It is not an alert system. It does not predict, explain, or draw conclusions. It collects. It organizes. It records. The world generates events at a rate that doesn't require embellishment. This system just writes them down.
