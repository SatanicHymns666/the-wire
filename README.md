# The Feed

Something breaks every day. The Feed writes it down.

This is an automated daily sweep of global news, organized into thirteen categories and logged with headlines, keywords, source names, and direct links. No editorializing inside the data. No analysis. No predictions. No recommendations. You can read it, run it through something else, or let it stack up in the archive. That's your call.

The categories are: Earth, Water, Sky, Infrastructure, Aviation, Maritime, Violence, Public Spaces, Political, Economic, Health, Space, and Unexplained. The data inside each category is structured and clean — one headline per line, keywords extracted, source named, URL attached. Between categories, you'll find commentary. That's the clerk reacting in real time to what was just filed. It builds across the day. It's accurate.

The system runs every morning UTC. It collects, deduplicates against the prior day's file, and writes a dated snapshot. Then it commits to the repo and goes silent until tomorrow. Nothing gets deleted. The archive begins in May 2026 and extends forward daily until something stops it.

You want to know what happened on a given day? Check the file. Want to know what the week felt like? Read three in a row. The world is very consistent about being the world.
