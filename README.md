# The Feed

The Feed is an automated daily news sweep. It runs once a day, casts wide across the wire, and writes down what the world did to itself. Earthquakes. Oil spills. Wildfires. Plane crashes. Disease outbreaks. Political collapses. Unexplained events. If it moved and made the record, it's here.

Each file is a dated snapshot. Headlines, keywords, source, URL. Organized by category. The categories don't change: Earth, Water, Sky, Infrastructure, Aviation, Maritime, Violence, Public Spaces, Political, Economic, Health, Space, Unexplained. Some days most of them are full. Some days the silence is its own entry. Both get filed.

This is not a news organization. It does not verify beyond what the public record shows. It does not predict outcomes. It does not explain what anything means. It collects what happened on a given day and organizes it before the next day starts. That's the job.

The world breaks things at a consistent rate. The rate is higher than people track. The Feed tracks it. Not to alarm, not to comfort — just to keep count. The archive exists so that when something happens and someone asks what else was happening at the same time, the answer is already written down.

Daily files live in the `feed/` directory. They are never deleted.
