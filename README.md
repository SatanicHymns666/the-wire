# The Feed

The Feed is a daily automated news sweep. It collects, organizes, and records what the world does to itself. No analysis. No prediction. No agenda. Thirteen categories, one file per day, every day. Headlines, keywords, sources, and links. Nothing else inside the data blocks.

The categories cover Earth, Water, Sky, Infrastructure, Aviation, Maritime, Violence, Public Spaces, Political, Economic, Health, Space, and Unexplained. Some days most of them are empty. Some days none of them are. Both are worth noting. The Feed doesn't editorialize on which kind of day is better. It writes things down.

This is an automated system. It runs daily on UTC time. Each file is a dated snapshot — a record of what could be confirmed, sourced, and linked on a given day. Entries are never fabricated and never repeated across consecutive files. If an event was filed yesterday, it doesn't appear again today unless the situation changed enough to warrant a new entry. Even then, only the new information is filed.

The data inside each category is clean and structured. Parseable. Other systems read these files and need the format intact. What you see between the categories is something else — a running note from whoever is doing the filing, losing composure at a measured rate as the list gets longer. Don't read into it. The data is the record. The rest is just the sound of a filing system reacting to its own contents.
